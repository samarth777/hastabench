# Group 1 verification (pataka tripataka ardhapataka kartarimukha mayura ardhachandra arala)
| hasta | verdict | key issue |
|---|---|---|
| pataka | MINOR | visible gaps between fingers (TOGETHER spread too loose: idx -7, ring +9, little +13); thumb more flexed (mcp 10-15, ip 20-30) |
| tripataka | MINOR | ring folded too deep; ring mcp 35 pip 95 dip 50, tip forward not in palm |
| ardhapataka | MINOR | ring+little folded too deep; ring 35/95/50, little 40/95/50 |
| kartarimukha | CORRECT | optional slightly wider V |
| mayura | MINOR | little splayed too wide (-12 -> -4), index slightly apart (+6 -> -3) |
| ardhachandra | CORRECT | inherits Pataka finger gaps |
| arala | MINOR | index should hook more (mcp 20 pip 92 dip 55); thumb lightly curled (mcp 12 ip 20); thumb position varies across sources |
Sources: Mirror of Gesture 1917 plates VII, X-XII (archive.org cu31924012568535), natyasutraonline gallery, Wikimedia Commons (X-Hasta + HasthamudraN sets), onlinebharatanatyam (flickr), natyarambha.wordpress.com (AD slokas), Alamy previews.
