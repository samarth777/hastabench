# Group 5 verification (samyuta)
| hasta | verdict | key issue |
|---|---|---|
| anjali | MINOR | joined pair turned ~35-40 deg in top view (asymmetric roll/yaw); force symmetric roll 90, yaw 0; add palm_heel contact |
| kapota | MINOR | palm heels not touching; add (R_palm_heel,L_palm_heel) contact; drop/replace palm-box apart |
| swastika | WRONG | palms face audience; refs show Pataka hands crossed at wrists, in profile (palms toward midline), narrow V; yaw ~15-20; fix DESCRIPTIONS |
| kartariswastika | MINOR | blades fan ~45 deg sideways vs pointing up; yaw ~15, optional inward roll 20-30 |
| pushpaputa | CORRECT | thumbs splay (inherited from sarpashirsha) |
Sources: naatyaanjali.com, kathakclub.com (same photo series), onlinebharatanatyam samyuta chart (flickr), ipassio illustrations, kalarasa blog (checked visually), Mirror of Gesture text.
Model limitation: forearm coaxial with hand, so horizontal-forearm + bent-wrist poses (swastika) cannot be shown exactly.
