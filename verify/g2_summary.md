# Group 2 verification (shukatunda mushti shikhara kapittha katakamukha suchi chandrakala)
| hasta | verdict | key issue |
|---|---|---|
| shukatunda | MINOR | ring folded deeper than index; equalise hooks: index 45/75/35, ring 50/80/35 |
| mushti | MINOR | thumb protrudes forward (T_OVER too straight); thumb flex 40 abd -15 rot 25 mcp 50 ip 35; keep thumb_dist-middle_mid, add thumb lying flat |
| shikhara | MINOR | thumb ~45 deg (want ~60, cmc_abd -15); DISPLAY roll 90 hides thumb in front view -> roll 0 + yaw 45-60 (thumb vertical) |
| kapittha | MINOR | thumb points forward (open pinch loop); thumb raised flex 0 abd -25; index 72/90/45 caps thumb tip |
| katakamukha | CORRECT | variants exist |
| suchi | MINOR | same protruding T_OVER thumb as mushti |
| chandrakala | CORRECT | clean L shape |
Shared: T_OVER thumb (mushti, suchi, kartarimukha, tamrachuda) too extended -> fix the constant.
Sources: Mirror of Gesture 1917 plates X-XIV (archive.org mirrorgesture00nand), natyasutraonline gallery, Wikimedia Commons, onlinebharatanatyam (flickr), lakshmi-ammans site.
