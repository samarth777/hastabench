# Group 4 verification (bhramara hamsasya hamsapaksha sandamsha mukula tamrachuda trishula)
| hasta | verdict | key issue |
|---|---|---|
| bhramara | CORRECT | index could curl slightly deeper toward thumb base |
| hamsasya | CORRECT | matches textual form; many dancers hold the 3 fingers together |
| hamsapaksha | MINOR | little finger only ~22 deg out vs ~60-90 deg in refs (abd limit +-25); thumb not alongside |
| sandamsha | WRONG | modelled as index-thumb pinch (Natya Shastra tongs); Abhinaya Darpana form = Padmakosha opened/closed, all 5 tips meet |
| mukula | MINOR | tips in a flat row, too much PIP bend, little finger not in cluster |
| tamrachuda | MINOR | index over-hooked (tip points down); thumb sticks out instead of pressing across middle finger |
| trishula | CORRECT | matches |
Fixes (agent proposal): hamsapaksha little_abd -40 (widen limit), 3 fingers tight, thumb cmc_abd -40/flex 15/mcp 20, apart little-ring;
sandamsha closed frame: idx 40/50/25 mid 45/50/25 ring 50/50/25 lit 55/50/25, spread(-6,0,6,12), T_OPP, contacts thumb-index/middle/ring, drop apart;
mukula: idx 35/20/10 mid 40/20/10 ring 45/20/10 lit 50/25/10, spread(-10,0,10,20), thumb flex55 abd0 mcp15 ip5, +thumb-ring contact, roll 0-30;
tamrachuda: index 0/70/30, thumb T_OVER (45,-10,mcp35,ip20), contact thumb_dist-middle_mid (+ring).
